# FundBar 小窗样式核验 · 2026-11-10

菜单栏预览小窗用系统 popover 材质（`VibrancyPopover`），内容只在材质上绘制：材质本身的颜色取自窗口背后的桌面，透出多少由系统决定，因此深色模式下背后是亮窗口时，整个小窗会变成一片灰雾，次要文字、涨跌胶囊和分隔线都读不出来。

## 调整

- 内容在系统材质之上加一层随主题的薄玻璃：深色 `#131317` 62%，浅色 `#f6f6f8` 60%。毛玻璃保留，背景不再把文字冲淡。
- 玻璃上的主题单独调过：次要文字更亮（深色 `#b6b6c4`，浅色 `#5f5f6d`），分隔线与边框更清晰，按钮与悬停底色比面板亮一档。
- 涨跌胶囊加大到 52 × 32，底色 16%、加一圈 20% 的同色边，字号 11.5；基金名称 13，代码与市值 11。
- 汇总金额 18 → 19；行内间距 9 → 10，文字变大而行高不变，小窗不多占地方。
- 底部「刷新」改为无底色的轻按钮，只有悬停时才出现底色；「打开主面板」保留填充按钮，主次分明。

## 切换分组

预览小窗的高度取自内容：切换分组时行数变化，窗口高度随之改变（一次到位，不再逐帧改）。逐帧改高度时窗口会把上一帧的画面拉伸到新尺寸，文字在动画期间发虚，因此过场改为横向：新分组的列表从右侧 20 DIP 滑入，200ms ease-out，同时由 30% 不透明度淡入，高度变化就藏在这段淡入里。

窗口因此仍用 `mygo` 的悬浮窗（`Vibrancy: VibrancyPopover`、`CornerRadius: 12`、系统阴影）而不是 `NSPopover`：后者每次改 `contentSize` 都会重算自身位置，整窗会抖。代价是没有指向菜单栏图标的箭头，图标按下时也不高亮。

## 验证

| 场景 | 结果 |
| --- | --- |
| 深色，背后为亮窗口 | 小窗保持深色，名称、代码、市值与胶囊均可读 |
| 深色，背后为彩色壁纸 | 只透出少量色调，红绿涨跌仍清晰 |
| 浅色 | 玻璃偏白，胶囊与分隔线比之前更清楚 |
| 无自选 / 分组为空 | 两行提示与之前一致，玻璃同样生效 |
| 刷新中 | 轻按钮左侧出现转圈，按钮不再响应点击 |
| 持有（4 只）↔ 关注（2 只） | 新列表从右侧滑入并淡入；高度一次到位，动画期间文字不虚 |

深色与浅色的对比度按模拟材质核对；实机窗口材质与阴影由系统绘制，仍需在 macOS 上确认。

回归用例 `TestPreviewSlidesTheListOfANewGroup` 在 `internal/app/panel_test.go`：切换分组后 60ms 时行的横坐标应偏右（正在滑入），300ms 后回到原位。

完成检查：`gofmt`、`go vet ./...`、`go tool mygo vet .`、`go test -timeout 180s ./...`。
