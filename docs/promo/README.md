# 宣传图

[返回项目首页](../../README.md)

README 海报由 [`tools/promo`](../../tools/promo/main.go) 直接调用当前版本的 `app.View` 与 `app.Panel` 渲染，再用 MyGo 绘制品牌文字、背景、弧线及阴影。全程本地执行，不调用图片生成服务，也不重画截图里的文字、数值或图表。

## 一条命令更新

在仓库根目录运行，需要与应用相同的 Go 环境：

```sh
go run ./tools/promo
```

每次运行都从当前源码重新绘制 UI，并覆盖本目录中的六张 PNG 和 `manifest.json`。修改布局或主题后重新运行即可；不必先编译安装应用。

默认读取 `~/Library/Application Support/FundBar/cache/` 中四只示例基金的缓存：`011555`、`007760`、`008270`、`028678`。如缺少缓存，先在应用中添加对应基金并刷新，或指定已有缓存的代码。最后一个代码作为主面板选中项，最多展示四只。

```sh
go run ./tools/promo -codes 011555,007760,008270,028678
go run ./tools/promo -data /path/to/FundBar -out /tmp/fundbar-promo
```

`-data` 指向包含 `cache/` 的数据目录。生成器把所选行情快照复制到临时目录，让两种主题、主面板与小窗共享同一份数据；结束后自动清理临时目录。

## 数据与截图口径

- **UI 是当前源码，行情是本地缓存。** 生成过程不请求行情接口，不把缓存伪装成实时数据；图中的「尚未更新」保留应用离线加载时的实际状态。
- **持仓是示例。** 每只基金使用 1000 份，成本等于其最新缓存的已公布单位净值。收益由现有应用逻辑计算；生成器不读取或修改用户的 `funds.json`，不展示用户真实份额和成本。
- **截图来自离屏渲染。** 不包含桌面、系统菜单栏或其他应用；主界面使用不透明侧栏，菜单栏小窗使用应用的毛玻璃主题与模拟系统材质。实际 macOS 毛玻璃会随桌面背景变化。
- **两种主题的数据一致。** 所有截图使用同一组行情快照和示例配置，不修改基金名称、净值曲线或涨跌颜色。
- **可追溯生成来源。** `manifest.json` 记录所用源码、输入快照与输出图片的哈希。行情缓存或系统字体变化时，重新生成的结果也可能变化。

README 根据读者的浅色 / 深色偏好选择对应海报，并保留原图链接供放大查看。

此前准备的 [手动生图提示词](PROMPTS.md) 保留作设计方向参考；当前 README 使用本地代码生成的成图。
