## 提示词 C：只生成背景，后期叠放真实界面

如果生成模型会改坏中文或图表，使用此方案。无需上传截图，输出无字背景；之后将原始截图、图标与文字以普通图层叠放，可保持界面内容准确。建议最终 README 使用这种制作方式。

```text
为一款名为 FundBar 的 macOS 原生工具制作高端软件宣传 CG 的纯背景底图。横向 3:2，2400 × 1600 或更高分辨率。

珍珠白与极浅冰蓝色的抽象摄影棚空间，柔和漫射光。少量半透明磨砂玻璃带状弧面在画面右下角与最右边缘延伸出画面，局部极克制的蓝紫色折射，精细的环境阴影与真实玻璃材质。

顶部 25% 保持近乎纯净的浅色留白，后期将放标题；中部及左下部约 70% 保持平整安静，后期将放软件截图。玻璃结构不要横穿中心，不要占据主体位置。整体干净、明亮、轻盈、有精致的空间深度。

只生成背景。不要文字、字母、数字、图标、界面、设备、图表、金币、植物、人物、水印或立柱展台。没有明显地平线，没有浓烈霓虹，不要复杂纹理。
```

## 成图检查与使用

- 窗口、品牌图标完整，图表和中文没有变形、拼错或被装饰挡住。
- 主窗口与菜单栏小窗的层次明确，在 README 常见宽度下仍能辨认产品形态。
- 不出现截图原本没有的功能或投资回报承诺。
- 导出高分辨率 PNG，建议文件名为 `hero-light.png`、`hero-dark.png`；保留未压缩原图，接入 README 时再生成适当体积的展示版本。
- README 图下注明：`真实界面素材合成；截图数据仅作展示，盘中估值不等于实际净值。`
